# Shared 3D assets

`brand/three/models.mjs` contains original procedural constructors for Pulse Roof/plinth, anonymous terrace/condo/bungalow, 24-drawer apothecary, demo card and fallback store. `npm run models` exports GLBs and a SHA-256 manifest. No real development or stock model is depicted.

Blender scripts generate the reception, lounge, cabinet, two private rooms and urgent-call booth. They export GLB, editable `.blend` sources and Cycles PNGs.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python blender/build_store.py
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python blender/build_apothecary.py
ffmpeg -y -i public/images/store-concept.png -quality 86 public/images/store-concept.webp
npm run build
npm --prefix reels run prepare:assets
```

Validated with Blender 5.2.2 LTS, Cycles 48 samples, denoising and 1280×800 output. Adjust the executable path for your machine. CPU rendering takes several minutes. GLB does not reproduce every procedural Cycles material node; the real-time model is a spatial study.

## Replace the concept

Current dimensions are **8 × 12 × 3.1 m**, an unconfirmed 96 m² study in `blender/store-config.json`. A measured twin requires an approved plan, openings, room positions and material specifications. The current generator supports two rooms; a different layout needs geometry changes.

After editing the configuration, regenerate and inspect the Blender scene/still and three reel ratios, then prepare runtime assets. Website build takes `brand/3d/store.glb`, falling back to `store-concept.glb` when absent. Remotion has a procedural load-failure fallback. Neither confirms real dimensions.

`store-provenance.json` records status/dimensions. `manifest.json` covers procedural GLBs; `artifact-manifest.json` inventories procedural and Blender outputs. Runtime copies under `public/models` and `reels/public/models` are ignored and regenerated.

This is not a construction drawing, fit-out specification, accessibility approval or confirmed tenancy. On 2026-10-01 the user accepted retaining the explicitly labelled concept for this delivery. An approved measured plan is required only when replacing it with an actual store twin.
