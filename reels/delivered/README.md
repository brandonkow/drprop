# Release candidate reels

English-only MP4s. Technical verification is `npm run verify:media -w @drprop/reels`.
The hash manifest also checks dimensions, duration, frame rate, audio, colour tags,
full decoding and loudness. Passing does not approve business claims or music rights.
Founder content/fee review and soundtrack clearance remain required before publication.
Fictional quarterly market examples live in `../samples/` and are not publication candidates.
