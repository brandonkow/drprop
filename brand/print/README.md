# English print release

`npm run print -w @drprop/brand` generates the English sample report, diagnosis card
and fee plate. Add `-- --plate-only` to regenerate just the plate. Existing Chinese
and Malay outputs are historical source archives, not current release deliverables.
Fees and opening hours remain provisional pending founder approval. The current
plate is `out/fee-plate.pdf`; rendered QA is in `docs/qa/fee-plate-en-2026-10-13.png`.
